# AI 内容检测器

一个纯前端网页工具，用于检测图片和文本是否由 AI 生成。所有分析均在浏览器本地完成，不会上传任何数据。

## 功能

### 图片检测
- 解析 **JPEG / PNG / WebP / AVIF** 格式图片
- 提取 EXIF 元数据，识别 AI 工具签名（DALL·E、Midjourney、Stable Diffusion 等）
- 检测 C2PA / JUMBF 内容凭证
- 读取 XMP 元数据查找 AI 生成痕迹
- 提供**人工辨别清单**（8 项图片异常指标：手指畸形、伪文字、塑料感皮肤等）

### 文本检测
- **词汇多样性（TTR）**：统计独立词汇占比，AI 产出通常词汇重复度更高
- **句式变化度（Burstiness）**：分析句子长度分布，人类写作句子长短不一
- **高频重复模式**：检测重复出现的三元词组（trigram）
- **AI 常用短语**：匹配 30+ 个 AI 写作高频短语
- **词长变化度**：分析单词长度分布的变化程度

### 界面
- 明/暗主题切换，跟随系统偏好
- 毛玻璃（Glassmorphism）视觉风格
- 响应式布局，适配移动端

## 使用方式

直接在浏览器中打开 `index.html` 即可使用，无需构建或后端服务。

## 技术栈

- 原生 HTML / CSS / JavaScript，零框架依赖
- 二进制文件解析（JPEG EXIF、PNG chunk）均在前端完成
- 文本分析采用分块异步处理，避免阻塞 UI

## 依赖

```bash
npm install
```

仅 `playwright` 一个 npm 依赖（用于自动化测试或截图）。核心检测功能不依赖任何 npm 包。

## 注意事项

本工具采用启发式算法，检测结果仅供参考，不能作为判断 AI 生成的绝对依据。熟练的提示工程（Prompt Engineering）可以绕过文本检测，图片元数据也可被清除或伪造。
